# Reactor Control by P1KaChU337

Программа мониторинга, контроля и защиты реакторного комплекса для сервера **McSkill HiTech 1.12.2**
на базе мода **OpenComputers**.

Соавтор: **oGoOgO** — за идею программы и отчасти дизайн (элементы интерфейса и их расположение
взяты из его старой программы контроля реакторного комплекса).

## Установка и обновление

Одна команда и для установки с нуля, и для обновления:

```
wget -fq https://raw.githubusercontent.com/P1KaChU337/Reactor-Control-for-OpenComputers/main/installer/install_v2.lua /home/rc_install.lua && /home/rc_install.lua
```

- Установщик сам проверит компьютер, скачает файлы и в конце перезагрузит компьютер с запуском программы.
- Если стоит **v1**, её настройки (порог, игроки, тема) переносятся автоматически. v1 с включённой проверкой
  обновлений сама предложит обновиться до v2.
- Дальше программа сама проверяет обновления раз в час и показывает окно с описанием изменений.
  Обновить вручную: `/home/reactorcontrol/update.lua`.

Программа ставится в `/home/reactorcontrol/`, настройки и журнал — в `/home/reactorcontrol/data/`.

### Требуемые компоненты

Монитор 3 уровня, серверная стойка с сервером 3 уровня, видеокарта 3 уровня, процессор 3 уровня,
ОЗУ 3.5 ×4, жёсткий диск, интернет-карта, клавиатура, EEPROM с Lua BIOS, дисковод с OpenOS для установки ОС.
Реакторы, МЭ-контроллер (или интерфейс) и Flux-контроллер подключаются через адаптеры. Чат-бокс — по желанию.

## Как работает защита

- **Буфер каждого жидкостного реактора** проверяется каждую секунду и считается в секундах работы по реально
  измеренному расходу. Реактор останавливается, если буфера осталось меньше чем на 5 секунд — заранее,
  чтобы хватило на безопасный перезапуск. Один пропущенный долив защиту не задевает.
- Если опустел буфер, значит хладагент не доходит из МЭ до реактора: реактор ждёт **ручного запуска**.
  После 3 ручных запусков при пустом буфере реактор блокируется — проверьте подключение и запустите его
  через интерфейс самого реактора.
- Если хладагента в **МЭ** меньше порога или МЭ недоступна, жидкостные реакторы останавливаются и **запускаются
  сами**, когда всё восстановится. Воздушные реакторы не затрагиваются.
- Если реактор пропал из сети (взорвался, сломан адаптер), он показывается как «Нет связи». Если его больше нет —
  нажмите «Забыть» на виджете.

Программа не проверяет правильность схемы реакторов. Неправильная сборка — на ваш страх и риск.

## Режимы запуска

| Команда | Что делает |
|---|---|
| `/home/reactorcontrol/main.lua` | обычный запуск с интерфейсом |
| `/home/reactorcontrol/main.lua --nogui` | текстовый режим: журнал и панель реакторов, управление с клавиатуры (`s`, `x`, `1-6`, `m`, `q`) |
| `/home/reactorcontrol/main.lua --plain` | только строки журнала в терминал |

## Чат-команды (чат-бокс)

Работают только для игроков из белого списка (настраивается в окне настроек).

`@help`, `@status`, `@start [n]`, `@stop [n]`, `@setporog <mB>`, `@useradd <ник>`, `@userdel <ник>`,
`@forget <n> [renum]`, `@changelog [версия]`, `@info`, `@restart`, `@exit`.
