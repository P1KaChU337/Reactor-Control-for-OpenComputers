# probe — опрос компонентов в игре

Собирает в `/home/probe_report.txt`:
- список всех компонентов;
- методы `htc_reactors`, ME, Flux и чат-бокса с флагом `direct` и документацией (`component.doc`);
- что возвращает каждый безопасный метод (`get*`, `is*`, `has*`, `can*`, без аргументов) у каждого реактора и сколько он занял;
- реальную стоимость вызова: 20 вызовов подряд.

По умолчанию **ничего не включает и не выключает**. У ME вызываются только методы из белого списка
(`getItemsInNetwork` только с фильтром `ae2fc:fluid_drop`), чтобы не тянуть огромные списки.

## Установка и запуск

```
wget -f https://raw.githubusercontent.com/P1KaChU337/Reactor-Control-for-OpenComputers/claude/keen-volta-rnypyl/tools/probe/probe.lua /home/probe.lua
probe
```

Опции:

| Команда | Что делает |
|---|---|
| `probe` | базовый отчёт |
| `probe --watch 60` | плюс 60 с показаний реактора #1 раз в секунду: видно, как тикают стержни, буфер, расход |
| `probe --watch 60 -r 3` | то же для реактора #3 |
| `probe --toggle 2` | **включает и выключает** реактор #2 и замеряет реакцию (спросит `YES`), потом возвращает исходное состояние |
| `probe --all` | опрашивает вообще все компоненты, а не только известные типы |

Лучше всего запустить два раза: когда реакторы стоят и когда работают (с `--watch 60`).

## Как отдать отчёт

```
pastebin put /home/probe_report.txt
```
Или открыть через `edit /home/probe_report.txt` и переписать важное.

Проверка без игры: `cd tools/emu && lua5.3 emu.lua scenarios/probe.lua`.
